COMSCI-2-MINI-DATA-SET

Student Test Scores – Mini Dataset
Project

Student Test Scores is a simple Python program that uses a 2D array (list of lists) to store and manage test scores of students in different subjects. It demonstrates how real-life school data can be organized and processed using arrays.

Overview

This project stores weekly test scores of students in a table-like structure using a 2D array. Each row represents a student, and each column represents a subject. The program allows accessing, updating, displaying, and summarizing the data clearly.

Problem Statement

Teachers and students need a simple way to organize and review test scores. Without proper structure, scores can be confusing and difficult to manage. This project shows how a 2D array can organize student scores efficiently and clearly.

Objectives

Store student test scores using a 2D array

Access specific scores using indexing

Update scores when changes are needed

Calculate simple summaries like averages

Display organized test score data

Inputs

Student test scores

Subject scores (Math, Science, English)

Outputs

Printed test scores in table format

Updated student scores

Average score of a student

Logic Plan (Pseudocode)

START
Create 2D array of student scores
Display all student scores
Access a specific score
Update a selected score
Compute the average score of one student
END

Tech Notes

Uses Python 2D lists

No external libraries required

Implemented using basic Python functions (sum, indexing)

Designed for beginner-level understanding

Ethical Consideration

This project follows ethical programming practices inspired by the Association for Computing Machinery (ACM) Code of Ethics. All code is original, properly documented, and does not collect or store sensitive personal data.
