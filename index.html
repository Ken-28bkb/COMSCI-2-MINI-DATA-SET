Student Test Scores – Mini Dataset Project

Overview

This project demonstrates how to use a 2D array (list of lists) in Python to store and manage student test scores in different subjects. It shows how real-life school data can be efficiently organized and processed.

  • Rows represent students
  • Columns represent subjects (Math, Science, English)

The program allows users to access, update, display, and summarize the data clearly.

Problem Statement

Teachers and students need a simple way to organize and review test scores. Without proper structure, scores can become confusing and difficult to manage. This project uses a 2D array to organize student scores efficiently and clearly.

Objectives

  • Store student test scores using a 2D array
  • Access specific scores using indexing
  • Update scores when changes are needed
  • Calculate summaries like averages
  • Display organized test score data

Inputs

  • Student test scores
  • Subject scores (Math, Science, English)

Outputs

  • Printed test scores in table format
  • Updated student scores after changes
  • Average score of a student

Logic Plan (Pseudocode)

START
    Create 2D array of student scores
    Display all student scores
    Access a specific score
    Update a selected score
    Compute the average score of one student
END

Tech Notes

  • Uses Python 2D lists
  • No external libraries required
  • Implemented using basic Python functions (sum, indexing)
  • Designed for beginner-level understanding

Example Python Code

# Sample Python code for managing student test scores
students = [
    [85, 90, 78],  # Student 1: Math, Science, English
    [92, 88, 95],  # Student 2
    [76, 85, 80]   # Student 3
]

# Display scores
for i, scores in enumerate(students):
    print(f"Student {i+1}: Math={scores[0]}, Science={scores[1]}, English={scores[2]}")

# Update a score
students[0][1] = 95  # Update Student 1 Science score to 95

# Calculate average of Student 1
average = sum(students[0]) / len(students[0])
print(f"Student 1 Average: {average}")
