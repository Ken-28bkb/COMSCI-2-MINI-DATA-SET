# COMSCI-2-MINI-DATA-SET

## GradeTrackr – Student Grade Management Web App

GradeTrackr is a web-based application that uses a 2D array (JavaScript array of arrays) to store and manage student grades across multiple subjects. It demonstrates how structured data can be manipulated efficiently using basic programming concepts and web technologies.

---

## Overview

The system organizes data using a 2D array:

- Rows represent students  
- Columns represent subjects  

The application allows users to dynamically add, remove, update, and retrieve student grades in an interactive interface.

---

## Problem Statement

Managing student grades manually can lead to disorganized records, difficulty in updating data, and inefficient retrieval of information. This project provides a structured and digital solution to manage grades more effectively using a table-based system.

---

## Objectives

- Store student grades using a 2D array  
- Dynamically add and remove students and subjects  
- Access specific grades using indexing  
- Update grades through direct input or upgrade feature  
- Display structured data in a table format  
- Ensure input validation for accurate data handling  

---

## Features

- Add, rename, and remove **subjects**
- Add, rename, and remove **students**
- Input grades (limited to 0–99)
- Display grades in a dynamic table
- Retrieve a specific grade using student and subject number
- Upgrade (update) grades manually
- Numbered indexing system for clarity
- Clean and organized user interface

---

## Inputs

- Student names  
- Subject names  
- Grade values (0–99)

---

## Outputs

- Table displaying student grades  
- Updated grades after modification  
- Retrieved grade based on input  

---

## Logic Plan (Pseudocode)

START  
  Create empty arrays for students, subjects, and grades  
  Add student/subject dynamically  
  Store grades in 2D array  
  Display table  
  Allow grade update  
  Allow grade retrieval  
  Allow deletion of entries  
END
